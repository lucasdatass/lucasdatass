# Sobre Mim 👋

Sou um profissional focado na intersecção entre segurança transacional e inteligência de dados. Atualmente, atuo como **Analista de Prevenção a Fraudes II**, dedicando minha rotina à proteção de operações de crédito e cartões, mitigando riscos e identificando padrões suspeitos com base em análises rigorosas.

Movido pelo desejo de otimizar processos e transformar dados brutos em decisões de segurança automatizadas, estou me graduando em **Ciência de Dados**. Desenvolvo projetos práticos aplicando programação em Python, lógica de dados e manipulação de bancos de dados relacionais (ANSI SQL e MySQL) para desenhar soluções escaláveis de monitoramento e inventário.
